# Comic Reader

App desktop (Electron + React + TypeScript) para importar, ler e organizar HQs (CBZ/CBR/PDF) localmente.

Em desenvolvimento, seguindo a especificação em [docs/](docs/README.md). Veja [CLAUDE.md](CLAUDE.md) para as regras de arquitetura.

## Desenvolvimento

```bash
npm install
npm run dev         # app em desenvolvimento, com HMR
npm run typecheck
npm run lint
npm test
```

> O README completo (instalação, build de produção, onde ficam os dados do usuário) é escrito no milestone de release — ver [docs/08-plano-de-implementacao.md](docs/08-plano-de-implementacao.md#m8--release-v10).
