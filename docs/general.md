# Descrição

O projeto é um aplicativo desktop que deve permitir que o usuário possa fazer upload de suas hqs, e ler.Também deve permitir organizá-las em listas, sagas, funções essenciais para um fã de hqs no geral.

# Funcionalidades

## Leitura

- Opção de zoom.
- Trocar de página através das setas direcionais do teclado e mouse.
- Opção de tela cheia.
- Opção de portrait com zoom para uma leitura mais confortável.
- Opção de desligar a luz (Dark mode).
- Salvamento da página atual ao sair do aplicativo.

## Upload

- Permitir arquivos do formato CBR e CBZ, e também arquivo zipado com vários arquivos desses mesmos tipos.

## Gerenciamento

- Opção de organização em listas/sagas com nomes e opção de capa.
- Opção de deleção de hqs e listas/sagas.
- Opções de edição de listas/sagas.

## Geral

- Lista de "Continuar onde parou".
- Lista de todas as HQs.

## Design

- Design moderno e minimalista "clean".
- Intuitivo.
- Responsividade.
- Menu deve ser side-bar do lado esquerdo.
- Tela relativamente escura, sem opção de Light Mode.

## Framework

- Electron (Vite/Typescript)

## O que o projeto não é

- Rede social de HQ.
- Não é necessário login.
