# 09 — Testing and quality

## 1. Pyramid

| Level | Tool | Target | Where |
|---|---|---|---|
| Unit | Vitest (node) | Utils (natural sort, normalize, detect), `computeSpreads`, navigation reducers/hooks | `*.test.ts` next to the file |
| Integration | Vitest (node) + in-memory SQLite + real fixtures | Repositories, `LibraryScanService`, `LibraryService`, `ReaderService`, `PageCacheService`, archives | `src/main/**/*.test.ts` |
| Component | Vitest (jsdom) + Testing Library | Components with logic (ComicCard states, toolbar, end panel) | `src/renderer/**/*.test.tsx` |
| E2E | Playwright (`_electron.launch`) | Critical flows in the real app | `tests/e2e/` |

Main services receive their Electron dependencies (`dialog`, `nativeImage`, `BrowserWindow`, `shell`) via injection. In tests they're replaced with fakes, and cover generation uses a fake that writes a fixed JPEG.

`better-sqlite3` is compiled for Electron's Node. To run it under Vitest's Node, either use the `test` script with `electron-rebuild` reverted **or** run Vitest via `ELECTRON_RUN_AS_NODE=1 electron node_modules/vitest/vitest.mjs`. This decision is recorded in `package.json` during M0.6.

## 2. What to test

### 2.1 Required (integration)
- **Library scan:** the cases from [05 §10](05-importacao.md#10-required-test-cases) — recursive indexing across chained folders, hash-based dedup keeping the first occurrence, removal of entries whose file disappeared from disk, adding/removing a root folder.
- **Next file in folder:** natural ordering (`01, 02, 10`) among files in the same `dirPath`, `null` when it's the only/last file.
- **Deletion:** index-only deletion (file stays on disk) and deletion with `deleteFile: true` (the file is only deleted when the path is inside a configured root folder; otherwise it aborts the disk deletion but still removes it from the index).
- **Progress:** `setPage` debounce + `flush()` writes the last value, `complete` sets `completed_at`, "mark as unread" resets it, derived status is correct in all 3 cases, and "Continue reading" filters and sorts correctly.
- **Library:** accent-insensitive search ("acao" → "Ação"), every status filter, favorites, and every sort with a stable tiebreak.
- **Cache:** extraction generates files + `.complete`, dimensions are written, and LRU removes the oldest without touching the open comic.

### 2.2 Unit
- `naturalSort`: `['10.jpg','2.jpg','1.jpg']` → `1, 2, 10`, and subfolders.
- `isIgnoredEntry`: `__MACOSX/`, `._x.jpg`, `Thumbs.db`.
- `detectFormat`: zip, rar4, rar5, pdf, and unknown signatures.
- `computeSpreads`: cover alone, wide page alone, `offset`, unpaired final page.
- `titleFromFileName`: `Batman_-_Year_One_01.cbz` → `Batman - Year One 01`.

### 2.3 E2E (Playwright + Electron)
Each test runs with a temporary `userData` (via the `COMIC_READER_USER_DATA` environment variable, honored only when `!app.isPackaged` or in test mode).
1. **Add folder and read:** adds a root folder (dialog bypassed via `COMIC_READER_E2E`/`COMIC_READER_E2E_FOLDER` in test mode), waits for the scan, opens a CBZ, advances 3 pages with `→`, closes the app, reopens it, and confirms it's on page 4.
2. **Next file in folder:** puts 2 comics in the same folder, reads the last page of the first, and confirms the panel suggests the second (natural ordering).
3. **Modes:** switches between the 3 modes on the same comic, with no console errors.
4. **Deletion:** deletes a comic without checking "delete file" (confirms it disappears from the grid and the file stays on disk) and deletes another with the option checked (confirms the file also disappears from disk).

The memory test (RNF-03, `memory.spec.ts`) generates 300 PNGs and scrolls through the whole comic; being heavy, it only runs with `E2E_MEMORY=1`. The others (`smoke`, `robustness`) always run with `npm run test:e2e`.

## 4. Code quality

- **TypeScript:** `strict: true`, `noUncheckedIndexedAccess: true`, no `any` (`@typescript-eslint/no-explicit-any: error` rule).
- **ESLint:** `typescript-eslint` recommended-type-checked, `react-hooks`, `jsx-a11y` (recommended), and an import rule forbidding `electron`/`node:*` in `src/renderer` and `src/shared`.
- **Prettier:** 2 spaces, single quotes, `printWidth: 100`, trailing commas.
- **Names:** files in `kebab-case.ts`, components in `PascalCase.tsx`, and hooks with `useX`. Code and identifiers in **English**; UI text in pt-BR via i18n; comments and docs in pt-BR.
- **Commits:** Conventional Commits (`feat(reader): virtualized vertical mode`), referencing the RF when applicable (`Refs: RF-33`).
- **`package.json` scripts:** `dev`, `build`, `dist`, `typecheck`, `lint`, `format`, `test`, `test:e2e`, `db:generate`, `seed:dev`, `fixtures`.

## 5. PR review checklist

- [ ] Covers an RF/RNF and cites it.
- [ ] Contracts (03/04) updated if they changed.
- [ ] New IPC input has a zod schema.
- [ ] No file path coming from the renderer (IDs only).
